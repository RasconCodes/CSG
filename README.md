# Clay Stamp Maker

A simple browser-based tool for creating **3D-printable clay stamps** from your own fonts.

Upload a `.TTF` or `.OTF` font, choose a letter or number, adjust the stamp settings, preview the result in 3D, and export it as an STL.

## Features

*  Use your own **TTF/OTF fonts**
*  Raised lettering for stamping clay
*  Recessed lettering on the handle for identification
*  Interactive **3D preview**
*  Export individual **STL files**
*  Generate a complete **A–Z + 0–9 ZIP**
*  Adjustable stamp size, letter depth, handle height, and engraving depth
*  Runs entirely in your browser — **no CAD software or account required**

## Use It

**[Open Clay Stamp Maker](https://sirmcmitts.github.io/Clay-Stamps-Gen/)**

Your font is processed locally in your browser and is not uploaded to a server.
